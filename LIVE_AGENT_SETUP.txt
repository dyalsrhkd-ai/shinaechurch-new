신애교회 유튜브 라이브 방송 에이전트 설치 안내
================================================

대상 환경
- Windows 8.1
- OBS Studio 27
- obs-websocket 4.9.1(v4)
- WebSocket 주소: ws://127.0.0.1:4444

주의
- OBS 28 이상 내장 WebSocket의 기본 포트 4455는 현재 방송 PC에 적용하지 않습니다.
- 기존 운영 EXE를 바로 덮어쓰지 말고 별도 폴더에서 시험한 뒤 교체합니다.
- 에이전트 토큰과 OBS 비밀번호를 메신저, Git, 홈페이지 dist 폴더에 넣지 않습니다.

파일 배치
1. 배포받은 EXE와 live-agent.example.json을 같은 폴더에 둡니다.
2. 예제 JSON을 해당 부서 이름으로 복사합니다.
   - 아동부: live-agent.children.json
   - 중고등부: live-agent.youth.json
   - 청년부: live-agent.young.json
   - 중고등부·청년부 통합: live-agent.youth-young.json
   - 대예배: live-agent.main.json
3. JSON에 서버에서 발급한 1회용 원문 agentToken과 해당 PC의 OBS 비밀번호를 입력합니다.
4. managedStreamKeys는 단일 부서면 해당 키 하나, 통합 EXE면 ["youth", "young"]으로 입력합니다.

OBS 설정
1. OBS 27에서 obs-websocket 설정을 엽니다.
2. 서버 사용을 켜고 포트를 4444로 설정합니다.
3. JSON의 obsPassword를 OBS 설정 비밀번호와 동일하게 맞춥니다.
4. OBS를 먼저 실행한 다음 새 EXE를 수동 실행합니다.

방송 PC 검증 순서
1. EXE 로그에서 API 연결과 OBS 연결 성공을 확인합니다.
2. 관리자 라이브 화면에서 해당 부서의 시작을 누릅니다.
3. OBS 송출, YouTube Studio 시작, 홈페이지 영상 표시를 차례로 확인합니다.
4. 종료를 눌러 OBS와 홈페이지가 모두 종료 상태로 바뀌는지 확인합니다.
5. 네트워크를 잠시 끊었다 복구해 에이전트가 다시 연결되는지 확인합니다.
6. 모든 방송 PC 검증이 끝날 때까지 기존 EXE를 롤백용으로 보관합니다.

보안 마무리
- 모든 부서가 새 EXE로 전환되면 과거 소스와 문서에 사용했던 Firebase, OBS, YouTube 비밀값을 폐기하고 재발급합니다.
- 실제 live-agent.<부서>.json 파일은 서버나 Git에 올리지 않습니다.
