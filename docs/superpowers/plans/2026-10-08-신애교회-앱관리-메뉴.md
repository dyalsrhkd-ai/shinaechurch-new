# 홈페이지 관리자 「신애교회 앱관리」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈페이지 관리자 사이드바의 「신애교회 앱관리」에서 교인앱(관리 모드)을 폰·폴드와 똑같은 화면으로 띄워 앱 관리 전체를 하게 한다.

**Architecture:** 앱(`shinae-community`)에 `?embed=admin` 관리 모드를 더하고(인트로·가입·첫 안내·웹푸시 끔, 관리자만, 넓은 PC 칸 숨김) Pages 헤더로 홈페이지 안에서만 띄우게 한다. 홈페이지는 앱을 띄우는 칸 하나(`public/app-admin-panel.js`, `window.ChurchAppAdmin.mount`)를 만들고, 운영은 기존 다리 스크립트(`public/app-install-links.js`)가 메뉴를 끼우고 `#/admin/dashboard?view=app` 에서 그 칸을 그린다. React 소스(`AppAdmin.jsx`)도 같은 칸을 불러 쓴다.

**Tech Stack:** React 19 + Vite(앱·홈페이지), node:test, Playwright(msedge), Cloudflare Pages(wrangler), 교회 FTP(curl).

## Global Constraints

- 기준은 폰·폴드 앱이다 — 앱에서 안 보이는 칸은 웹에서도 안 보인다(`right-column` 숨김).
- 모양 단추: 작은 폰 344(폴드 접음) / 보통 폰 412(갤럭시·아이폰, 기본) / 넓은 화면 860(폴드 펼침·태블릿). 폭 320~1200.
- 흐림 금지: `transform: scale` 금지, 줄일 때만 CSS `zoom`.
- 운영 메뉴 주소 `#/admin/dashboard?view=app`. 운영 반영은 다리 스크립트로만. FTP 비밀번호는 요셉님이 직접 입력.
- APK 새 버전 없음(Pages 웹만). 홈페이지 저장소의 남의 미커밋 변경은 커밋하지 않는다(새 파일만 커밋).
- 모든 문구 한국어. 이모지는 기존 관리자 메뉴 관례대로 📱 하나.
