# 라이브 방송 관리 화면 간편화 (2026-10-12)

요셉님: "관리자 화면에 입력할 게 많다. 컴맹이 와도 되게." → 화면을 「오늘 방송」과 「처음 설정」으로 나누고, 크롬 프로필 폴더명은 방송 PC 프로그램이 알아서 찾게(요셉님 승인).

## 지금
`#/admin/live-streams/:streamKey`(LiveStreamManager) 입력 7칸이 한 화면에 섞여 있다: 방송 제목, 유튜브 채널 ID, 크롬 프로필 폴더명, 비밀번호, 전용 링크 키, 설교 제목, 본문. 버튼 3개(설정 저장·송출 시작·송출 종료), 상태 칸은 "OBS 에이전트", "제어 명령" 같은 개발 용어.

## 바꾼 뒤

### 1. 화면 (다리 스크립트로 끼움 — 운영 SPA 는 다시 빌드하지 않는다)
- 새 파일 `public/live-simple-panel.js`, 다리 스크립트(`app-install-links.js`)가 `#/admin/live-streams/<key>` 일 때 원래 본문을 숨기고 이 칸을 띄운다(「신애교회 앱관리」와 같은 방식). 다른 주소로 가면 원래 화면으로 돌아간다.
- **오늘 방송**
  - 신호등: 방송 PC 마지막 연락이 60초 안이면 초록 "방송 PC 준비됨", 아니면 빨강 "방송 PC가 꺼져 있습니다. 방송실 컴퓨터를 켜 주세요."
  - 설교 제목·본문 말씀 2칸.
  - 큰 버튼 하나: 방송 중이 아니면 「▶ 방송 시작」, 방송 중이면 「■ 방송 끝내기」. 시작은 두 칸을 저장한 뒤 시작 명령. 끝내기는 확인을 한 번 묻는다.
  - 진행 단계: ① 방송 PC에 전달 ② OBS 송출 중 ③ 유튜브 라이브 시작됨(영상 ID 생김). 실패하면 쉬운 말 + 서버가 준 사유.
  - 첫 설정(채널 ID)이 없으면 버튼 대신 "처음 설정을 먼저 해 주세요" 안내.
- **처음 설정** (접힘): 유튜브 채널 주소 또는 ID, 유튜브 방송 계정(방송 PC가 보내 준 크롬 프로필 목록에서 고름, 「자동」 기본), 방송 제목, 시청 비밀번호, 공유 링크(새로 만들기·복사). 저장 버튼 하나.
- API 는 기존 그대로: `live.php?action=admin|save|command`, CSRF 는 `auth.php?action=me` 의 `csrfToken`. 저장할 때는 서버에서 받은 설정 전체에 바꾼 칸만 덮는다(다른 칸 지우지 않음).
- 2초마다 상태를 다시 받는다(원래 화면과 같음).

### 2. 크롬 프로필 자동 (방송 PC 프로그램 EXE 5종)
- 새 공용 파일 `scripts/chrome-profiles.cjs`
  - `readChromeProfiles(userDataRoot)` → Chrome `Local State` 의 `profile.info_cache` 에서 `{ dir, name, email }` 목록(폴더가 실제 있는 것만) + `lastUsed`.
  - `pickChromeProfile(wanted, info)` → 저장된 폴더명이 있고 그 폴더가 있으면 그것, 아니면 프로필이 하나뿐이면 그것, 아니면 마지막으로 쓴 프로필(`last_used`), 그것도 없으면 `Default`.
- 5종 모두 `getYoutubeAutomationProfileName` 이 `pickChromeProfile` 을 쓰고, 상태 보고(heartbeat)에 `chromeProfiles` 목록을 싣는다.
- 서버 `normalize_live_status` 가 `chromeProfiles`(최대 10개, 글자 수 제한)를 통과시키고, 관리자 상태에 `seenAgo`(초)를 붙인다.
- 새 EXE 는 바탕화면에 두고 요셉님이 교회 PC에 설치(기존 EXE 는 롤백용으로 보관). 새 EXE 를 깔기 전에도 화면은 동작한다(목록이 없으면 「자동」/직접 입력).

## 시험
- `chrome-profiles.test.cjs`: 하나뿐·여럿(last_used)·저장값 우선·저장값 폴더 없음·Local State 없음.
- PHP: 운영 서버 시험 폴더에서 `normalize_live_status` 가 목록을 자르고 걸러내는지(PHP 5.5).
- 화면: `scripts/live-simple-browser.mjs` — 운영 관리자 화면에 로컬 칸 스크립트를 끼우고 API 는 가짜 응답. 꺼짐/켜짐 신호등, 시작 → save 후 command 순서, 방송 중 → 끝내기, 설정 저장이 다른 칸을 지우지 않음, 다른 메뉴로 가면 원래 화면 복귀, 390px 폭 가로 넘침 없음.

## 하지 않는 것
- 운영 SPA 다시 빌드, 원래 LiveStreamManager 소스 수정(남의 작업이 섞여 있음).
- 송출 흐름(OBS·유튜브 자동화) 자체 변경.
