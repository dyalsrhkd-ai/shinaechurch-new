# 홈페이지 관리자 계정을 교인앱 계정으로 통일 — 설계

작성 2026-10-08 · 요청·확정 요셉님

## 목적

관리자만 앱과 홈페이지 관리자 화면을 둘 다 쓴다(일반 교인은 홈페이지 관리자에 들어갈 일이 없다).
그러니 계정은 **교인앱 계정(Supabase) 하나**로 통일한다. 앱에서 「승인된 관리자」면 홈페이지 관리자에도 들어간다.

## 확정 사항(요셉님 10/8)

- 기준 표는 앱 계정. 홈페이지 관리자 추가·삭제·비밀번호는 앱에서(교인 관리의 관리자 지정).
- 지금 홈페이지 관리자들은 **앱 관리자로 옮긴다**(앱 가입 → 관리자 지정).
- **비상용 계정**: 지금 있는 홈페이지 관리자 계정(`admin_users` 의 비밀번호 있는 계정)은 그대로 남겨, 앱 서버(Supabase·Worker)가 멈췄을 때 요셉님이 들어갈 길로 쓴다.

## 구조

1. **Worker `POST /admin-login`**(`shinae-community/media-worker`): `{ identity, password }` →
   앱과 같은 규칙(`loginEmail`·아이디는 `/login-id` 와 같은 경로)으로 Supabase 비밀번호 확인 → 프로필이 `status=approved` 이고 `role=admin` 이면
   `{ ok, user: { uid, name }, access_token, refresh_token }`, 아니면 401(이유는 「아이디 또는 비밀번호가 맞지 않습니다」 하나로 — 관리자 여부를 흘리지 않음).
   실패 횟수 제한은 Worker 에서(같은 identity 5회/10분).
2. **운영 `auth.php` login**: 먼저 `admin_users` 의 비밀번호 계정(비상용)을 지금처럼 확인 → 없거나 틀리면 Worker `/admin-login` 에 물어본다.
   통과하면 `admin_users` 에 **그림자 줄**(login_id = `app-<uid 앞 8자리>`, display_name = 앱 이름, password_hash = 쓸 수 없는 값, must_change_password = 0, 앱 uid 보관 칸)을 찾아 쓰거나 만든 뒤 지금과 같은 홈페이지 세션을 연다(세션·활동 로그가 이 번호를 쓰므로).
   응답에 앱 토큰을 함께 실어 보낸다(`appSession`).
3. **앱관리 칸 바로 열림**: 다리 스크립트가 로그인 응답의 `appSession` 을 이 탭 sessionStorage 에 두고, 앱 칸(`app-admin-panel.js`)이 틀 안 앱에 `postMessage` 로 넘김 → 앱 관리 모드가 받은 토큰으로 `setSession`(보낸 곳이 홈페이지 주소일 때만 받음). 앱관리에서 다시 로그인하지 않는다.
4. **관리자 계정 설정 화면**: 그림자 줄은 목록에서 「앱 계정」 표시, 고치기·지우기 대신 「앱 교인 관리에서 하세요」 안내. 비상용 계정은 지금처럼 관리.
5. **반영**: Worker 배포(APK 새 버전 없음), 운영 PHP 는 받아서 필요한 곳만 고치고 백업 후 올림(FTP).

## 오류·예외

- Worker·Supabase 가 응답 없으면(8초) 홈페이지 로그인은 「앱 서버에 연결하지 못했습니다 — 비상용 계정으로 들어가세요」.
- 앱에서 관리자 지정을 풀면 다음 로그인부터 홈페이지도 막힌다(이미 열린 세션은 세션 시간까지).
- 카페24 PHP 가 밖(https Supabase·Worker)으로 나갈 수 있는지 먼저 작은 시험으로 확인한다. 막혀 있으면 이 설계를 멈추고 요셉님께 알린다.

## 시험

- Worker: `/admin-login` 단위 시험(관리자 통과, 교인·대기·정지·틀린 비밀번호 401, 횟수 제한).
- PHP: auth 서비스 시험(비상용 계정 먼저, 앱 관리자 그림자 줄 생성·재사용, Worker 실패 메시지).
- 운영: 앱 관리자 계정으로 홈페이지 로그인 → 대시보드 → 앱관리 칸이 로그인 없이 열림, 비상용 계정 로그인도 그대로 됨.

## 하지 않는 것

- 홈페이지 공개 화면 로그인(없음) · 교인 일반 계정의 홈페이지 접근 · 홈페이지 관리자 역할 나누기.
