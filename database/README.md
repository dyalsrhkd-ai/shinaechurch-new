# Cafe24 database

`cafe24-schema.sql`은 교회 홈페이지의 관리자, 콘텐츠, 방문 통계, 방송 제어 데이터를 저장하는 기본 스키마입니다.

## 최초 적용

1. Cafe24 phpMyAdmin에서 운영 DB를 선택합니다.
2. 가져오기에서 `cafe24-schema.sql`을 UTF-8로 실행합니다.
3. 테이블 10개가 생성됐는지 확인합니다.
4. 첫 관리자 계정은 배포 시 제공하는 서버 전용 초기화 절차로 한 번만 만듭니다. SQL에 비밀번호를 직접 넣지 않습니다.

## 전환 전 백업

phpMyAdmin의 내보내기에서 전체 테이블을 SQL로 내려받고 날짜를 붙여 보관합니다. 콘텐츠 변환 전과 운영 전환 직전에 각각 한 번 백업합니다.

## 주의사항

- 모든 테이블은 InnoDB와 `utf8mb4`를 사용합니다.
- 운영 DB 접속정보와 비밀번호는 웹 루트 밖의 서버 전용 PHP 설정 파일에만 둡니다.
- 저장소의 `config/cafe24.example.php`는 키 이름 예시일 뿐이며 운영값을 넣지 않습니다.
- Cafe24 환경이 외래키 생성을 막는 경우 오류를 기록한 뒤 외래키 절만 제거해 재실행할 수 있습니다. 인덱스와 애플리케이션 검증은 그대로 유지합니다.
- 기존 데이터가 있는 상태에서는 먼저 SQL 전체 백업을 받고 마이그레이션합니다.
